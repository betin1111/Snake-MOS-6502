# Snake-MOS-6502
Implementation of the classic Snake game in 6502 Assembly. An educational project focused on programming logic, memory manipulation, CPU registers, bitwise operations, movement, and collision detection.

🐍 Snake Game in 6502 Assembly

## About the Project

This project is an implementation of the classic Snake game using 6502 Assembly language.

The main goal was not simply to make the game work, but to understand how it works at a low level, exploring memory manipulation, CPU registers, bitwise operations, program flow, movement, and collision detection.

🎯 Learning Journey

I made a conscious decision to develop this project independently, taking the time to understand the concepts rather than simply copying and reproducing code.

Throughout the process, I restarted parts of the project several times, revisiting the fundamentals until I could understand the logic behind the instructions and how they interact with the processor.

Although most of the implementation followed the learning material, I gradually gained enough understanding to implement some parts based on my own reasoning and interpretation of the concepts.

For me, the most important achievement was not just completing the game, but reaching a point where I could read, explain, and understand the code I had written.

🧠 Concepts Practiced

- 6502 Assembly fundamentals
- CPU registers and processor flags
- Memory addressing and manipulation
- Bitwise operations
- Conditional branches and loops
- Snake movement and body updates
- Collision detection
- Game loop logic

🚀 Purpose

This is a learning project and part of my journey into low-level programming. It represents an important step in understanding how software interacts with hardware and how classic games can be built using a limited instruction set.

More than a finished game, this project is a foundation for future experiments and more complex implementations.

▶️ How to Run

This game was developed using the [Easy 6502 emulator](https://skilldrick.github.io/easy6502/), which runs directly in the browser.

To play:

1. Open the Easy 6502 emulator.
2. Copy the source code from this repository.
3. Paste it into the emulator's code editor, replacing the example code.
4. Run the program and enjoy the game!

No installation is required.
